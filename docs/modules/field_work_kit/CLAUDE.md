# Field Work Kit Module (Claude Notes)

## Status

The Field Work Kit module is not available in the community tier. Its screens, widgets, and services (weather, tides, staffing manifests) are gated behind Pro/Scale tiers and are not present in this codebase.

## Naming Conventions
- In-app variables, identifiers, map keys, and user-facing names use camelCase.
- File and directory names prefer snake_case when creating or renaming, but internal naming is the hard rule.
