# Archived Backfill Scripts

One-time data backfill scripts that have been executed.
Preserved for historical reference.

**DO NOT RUN THESE SCRIPTS** - they were designed for one-time backfills.

## Archived Scripts

- `backfill_event_metadata.js` - Backfilled event metadata fields
- `backfill_override_history_timestamps.js` - Backfilled override history timestamps
- `backfill_taxonomy_species_search_tokens.js` - Backfilled species search tokens
- `backfill-mote-coordinates.js` - Backfilled Mote location coordinates (untracked)

## Naming Conventions
- In-app variables, identifiers, map keys, and user-facing names use camelCase.
- File and directory names prefer snake_case when creating or renaming, but internal naming is the hard rule.
